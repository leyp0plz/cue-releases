Der UrsprungThe origin

Es begann nicht mit einem Video.

Es begann mit einem Klang.

Ein Riser, der einen ganzen Club anhebt. Ein Vocal Chop, drei Sekunden lang. Ein Effekt aus einem Live Set, den man nirgends kaufen kann.

Ich stehe hinter dem Pult und will genau diesen Moment in meinem Set. Nicht das ganze Video. Nicht das Bild. Nur den Ton. Nur diese Sekunden, ohne einen Hauch Qualität zu verlieren.

Also baue ich mir ein Werkzeug. Link hinein. Start und Ende setzen, wie zwei Cue Punkte auf dem Deck. Heraus kommt Audio: verlustfrei, sauber geschnitten, bereit fürs nächste Set.

Daher der Name: Cue.

Heute kann Cue auch Video. Aber im Herzen ist es geblieben, was es vom ersten Tag an war: ein Werkzeug für den Sound.

Luc Porchet, DJ

It didn’t start with a video.

It started with a sound.

A riser that lifts an entire club. A vocal chop, three seconds long. An effect from a live set that you can’t buy anywhere.

I’m standing behind the decks and I want exactly that moment in my set. Not the whole video. Not the picture. Just the sound. Just those seconds, without losing a trace of quality.

So I build myself a tool. Paste a link. Set start and end, like two cue points on a deck. Out comes audio: lossless, cleanly cut, ready for the next set.

Hence the name: Cue.

Today Cue does video too. But at heart it is still what it was from day one: a tool for sound.

Luc Porchet, DJ

Installieren

Install

Cue ist gesperrt, bis du einen Schlüssel von mir eingibst.

Cue stays locked until you enter a key from me.

Mac

  1. ZIP öffnen.
  2. Terminal öffnen, bash tippen (mit Leerzeichen).
  3. Die Datei … installieren.command ins Terminal ziehen, Enter drücken.
  4. Schlüssel einfügen, auf Unlock klicken.
  1. Open the ZIP.
  2. Open Terminal, type bash (with a space).
  3. Drag the file … installieren.command into Terminal, press Enter.
  4. Paste your key, click Unlock.

Windows

  1. ZIP rechts klicken, „Alle extrahieren“.
  2. Cue installieren.bat doppelklicken.
  3. Bei „Windows hat den PC geschützt“: „Weitere Informationen“, „Trotzdem ausführen“.
  4. Schlüssel einfügen, auf Freischalten klicken.
  1. Right-click the ZIP, “Extract All”.
  2. Double-click Cue installieren.bat.
  3. If “Windows protected your PC” appears: “More info”, “Run anyway”.
  4. Paste your key, click Unlock.
